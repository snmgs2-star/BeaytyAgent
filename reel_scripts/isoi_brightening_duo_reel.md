## 📊 台本設計の戦略まとめ

### ペルソナ × コンテンツ設計マッピング

| ペルソナ特性 | 台本での対応 |
|---|---|
| **品質重視** | 12年連続1位の客観データ、成分名を具体的に提示 |
| **効率重視** | 3in1の時短訴求、「2本で完結」のシンプルさ |
| **韓国渡航頻度高め** | 「オリヤン」「渡韓メモ」など当事者言語を使用 |
| **鵜呑みにしない** | 感覚ではなくデータ・成分・ロジックで語る |
| **短時間で結論** | 40〜50秒に収め、各セクション5〜10秒でテンポよく |
| **保存しやすい実用的コンテンツ** | 購入先・成分リスト・使い方を保存価値として設計 |
| **可処分所得あり** | 「投資する価値」のフレーミング、安さではなく品質訴求 |

### エンゲージメント施策

| 施策 | 狙い |
|---|---|
| 冒頭3秒で数字フック | 離脱防止・権威性 |
| 「忙しい人ほど」の共感 | ペルソナの自分事化 |
| 成分×効果のセット提示 | 保存価値（あとで見返したい情報） |
| 「オリヤンvs日本」二択 | コメント誘発 |
| 「渡韓メモに保存」 | 保存率UP |
| プロフィールリンク誘導 | 購入導線 |
