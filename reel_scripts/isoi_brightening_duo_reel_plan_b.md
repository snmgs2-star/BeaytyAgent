# 📱 Instagram リール台本（Bプラン）
## ISOI ツヤ玉ローズPDRNセラム × ジェラートパック洗顔

> **📌 Bプランの核心**: フック＝「権威性×ストレート宣言」。**1文目で12年連続1位の権威性、2文目で"ガチで別格"の主観評価**を同時に叩き込む。前置きゼロ・即商品紹介の最速構成。「何がすごいの？」と思った瞬間にはもうセラムの話が始まっている──完視聴率が跳ね上がる設計。

---

### 基本情報

| 項目 | 内容 |
|---|---|
| **尺** | 45〜55秒（完視聴率重視の設計） |
| **形式** | 顔出しトーク＋手元クロースアップ＋テクスチャーASMR的見せ＋肌ビフォーアフター |
| **トーン** | 「美容に詳しい友達が"これマジで良かった"と断言する」感。自信があって、でも押し売り感はない |
| **声のテンポ** | 冒頭は確信を持ったストレートな声（"別格だった"の断言）。中盤から落ち着いて成分解説 |
| **BGM** | ミニマルなピアノ or Lo-fi beats（韓国カフェ系）── 声を邪魔しない音量設計 |
| **ターゲットペルソナ** | 30〜35歳・会社員・品質重視・効率重視・韓国美容リテラシー高め・**結論から知りたい** |
